# UCF Website

This directory documents the frontend layer of the UCF ecosystem.

## Planned Components

* UCF ecosystem website
* wallet connection
* token information
* DeFi interfaces
* staking
* NFT marketplace
* governance
* blockchain network information

## Future Network Integration

The website will eventually provide access to:

* UCF Testnet
* UCF Scan
* UCF Mainnet
* developer resources
* network statistics

The website must clearly distinguish between testnet and mainnet environments.
